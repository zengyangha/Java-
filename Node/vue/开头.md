
# [[脚手架]]

## vue是用于创建web交互界面的库，是以数据驱动构建web界面的前端js框架，将数据和视图view完全分离的，即数据和view是分离的，将数据组件化

## vue的生命周期，钩子函数
- 创建期间
- beforeCreate  实例刚在内存中创建，还没初始化data和methods属性
- created  初始化data和methods属性，但没编译模板
- 运行期间
- beforeMount   完成译模板，但是没有挂载页面
- mounted  挂载好页面
- beforeUpdate  data状态更新了，但是界面没有更新，没有渲染dom节点
- update    渲染完成，
- 销毁期间
- beforeDestory    在这里实例还可以使用
- destory    实例销毁，vue实例绑定的东西都解绑，所有事物、监听器等被移除


## MVVM设计模式
- 配合服务器实现MVC设计模式
	- model模型 view视图 controller控制器 ，软件设计的典范
- modle view  view-model视图模型 
- el:提供vue可接收的dom元素作为vue实例的挂载目标，
- v-bind，属性绑定，可简写为：
- v-on绑定方法，事件，可简写为@
- ref  让其他组件通过ref获取dom元素引用
- v-slot  占位插槽，可简写为#


## 计算compute和监听watch的区别
- computed能完成的，watch都能完成
- watch能完成的，computed不一定能做
- 计算属性有缓冲
