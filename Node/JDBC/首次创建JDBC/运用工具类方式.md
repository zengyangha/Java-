## 先创建配置文件目录config或resource，并标记为资源根目录，在里面创建以properties为结尾的配置文件，在里面写好驱动路径driver，数据库连接url，数据库用户user和密码password

## 创建utils工具类的包，写好私有属性（和配置文件的一样），多创建个Connection对象，都设置默认为null，运用静态代码块来初始化属性

## 在静态代码块中创建Properties 对象，用来用于读取配置文件中的键值对，然后加载配置文件--》InputStream resourceAsStream = JdbcTools.class.getClassLoader().getResourceAsStream("jdbc.properties");    然后用配置文件的对象的load方法来接受加载配置文件的返回值，然后再读取配置项（driver,url等），内容时配置文件对象的getProperty（）方法，读的是键
- JdbcTools.class.getClassLoader().getResourceAsStream("jdbc.properties") 使用类加载器来读取资源文件。这种方式可以确保配置文件被正确加载，即使程序被打包成 JAR 文件时也是如此
- 使用 `InputStream` 可以更灵活地处理不同的输入源（例如文件、网络流等），并且适用于读取 JAR 文件内的资源
- 将配置文件放在外部，可以在不修改代码的情况下改变配置。这对于在不同环境（开发、测试、生产）下部署应用非常有用。只需更换配置文件即可，而不需要重新编译代码

## 这样基本的连接环境配好了，现在开始获取数据库链接的方法，返回一个数据库的对象connection，用if来判断是否为空或者关闭，然后用驱动程序管理器链接，connection = DriverManager.getConnection(url, user, password);

## 最好再创建关闭数据库资源的方法，用if来判断是否为空，否就close，方法名称为closeAll（xxxxxx）；

## 接下来是创建增删改的通用方法，形参为(String sql, Object... params)，返回类型为int，可创建int iret变量来表示影响的行数，然后创建connection和preparedStatement对象，默认为null，然后connection对象用获取数据库链接的方法来接收，而preparedStatement为准备语句对象，也是预编译的对象，用来执行预编译的 SQL 语句--》preparedStatement = connection.prepareStatement(sql);，然后用if判断参数不为空且有元素，用预编译的对象的setObject方法来设置参数preparedStatement.setObject((i + 1), params【i】);，注意i + 1表示当前参数的索引位置,setObject的parameterIndex 是从1开始的索引，因此需要加1，然后iret = preparedStatement.executeUpdate();来接收是否改变行数，最后调用cliseAll方法来关闭所有资源，然后返回iret，这样增删改功能完成了
- Object... params是可变参数写法，相当于数组
- PreparedStatement，
	- 用于执行预编译的 SQL 语句，这样，SQL 语句只需要编译一次，而不是每次执行时都重新编译。这提高了执行效率，尤其是在需要多次执行相同语句的情况，
	- 有效防止 SQL 注入攻击。因为PreparedStatement会将参数与 SQL 语句分开处理，参数会被转义，防止恶意代码注入
	- 允许使用 `?` 占位符来表示参数位置，然后通过方法（如 `setInt`、`setString` 等）将参数值传递给占位符。这使得代码更易读，也简化了参数处


## 接下来是查询功能，但在此之前，要先创建entity实体化包，创建对应数据库的表的名字的类，设置表的私有属性，生成get和set方法还有构造方法等


## 接下来是查询功能，参数不变，但返回类型变成List《实体类》，与增删改功能有点不同，多创建List《实体类》和ResultSet结果集对象，都默认为空，然后list、connection和prepareStatement初始化（和增删改同理），传递参数（可以不传参）也和增删改同理，然后到结果集来获取准备语句的返回结果，resultSet = preparedStatement.executeQuery();  接着遍历结果集，用while循环，限制为resultSet.next()，在循环里面新建刚刚创建的实体化对象，调用set方法获取变量，其参数为刚刚的结果集resultSet的相对get方法，getInt，getString方法等，而对应的参数为表的列名，然后让list通过add方法接收实体化对象，循环结束后最终关闭所有资源，然后返回list
- resultSet结果集，是个接口，主要作用是表示从数据库查询中返回的数据结果集

## 查询用法，在测试类中，要查询得写好sql语句，然后用List《实体类》 list=JdbcTools.query(sql,null);  query为查询方法，然后用增强for循环遍历打印即可

## 增删查方法都一致，先写sql语句，然后用Object的参数数组写要增删改的数据，然后int i = JdbcTools.eUpdate(sql, params);
