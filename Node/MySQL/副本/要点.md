## 事物：
- 事物可以保证数据库中的数据完整性和一致性
- 四大特性
	- 原子性：事务的原子性是指事务必须是一个原子的操作序列单元。事务中包含的各项操作在一次执行过程中，只允许出现两种状态之一，要么都成功，要么都失败
	- 隔离性：事务的隔离性是指在并发环境中，并发的事务是互相隔离的，一个事务的执行不能被其它事务干扰
	- 一致性：事务的一致性是指事务的执行不能破坏数据库数据的完整性和一致性，一个事务在执行之前和执行之后，数据库都必须处以一致性状态
	- 持久性：事务的持久性是指事务一旦提交后，数据库中的数据必须被永久的保存下来
- 关键字：
	- begin transaction 开启一个事务
	- commit 提交事务，如果事务成功，将进行持久化存储
	- rollback 回滚事务，事务失败后数据恢复到初始状态
	- autocommit 默认打开，自动提交事务，关闭则要手动提交事务，关闭事务相当于提交了一个事务
