# 点击回到[[MySQL]]

## 概念：
- 负责分配、管理和释放数据库连接，允许程序重复使用一个现有的数据库连接，而不需要再建立多个数据库连接，可以设置释放资源，设置释放空闲时间，避免没有释放数据库链接而引起的数据库连接泄漏

## 作用：
- 使用javax.sql.DataSource接口来表示连接池
- DataSource也只提供一个接口
- 未完待续

## 属性
- 可以设置连接池的属性，有四大要素
	- 驱动名称
	- 数据库url
	- 用户名
	- 密码
- 初始化连接数
- 最大、小连接数
- 最大、小等待/空闲时间

## 相关属性是要个配置文件绑定，配置文件是防止其他人修改，为了安全操作

## 连接池技术为DBCP，要导入相关jar包，但现在目前数据库连接池热门是Druid，阿里巴巴的第三方依赖包，其他几乎淘汰
