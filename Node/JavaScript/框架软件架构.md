# 点此回到[[JavaScript/开头]]

## 有两种模式
- C/S，客户端/服务器（client/server）,桌面级应用程序，需要客户端进行安装，或者升级
- B/S，浏览器/服务器(browser/server)，web应用程序，只需要浏览器，页面显示的都是最新的


## 资源分类
- 静态资源，用户访问后，得到的结果是一样的，可以被浏览器直接解析，html，css，javascript
- 动态资源，用户访问后，得到的结果是不一样的，动态资源在被访问后，需要先转换成静态资源，再返回浏览器，如servlet，jsp，php

## servlet
- 服务端小程序，接收请求，返回响应
- 有两个常用子关系
	- GenericServlet
	- HttpServlet
