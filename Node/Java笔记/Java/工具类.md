# 点此回到[[JAVA（由此开始）]]

## Collections
- addAll   批量添加
- .sort（）排序
- .binarySearch（）二分查找，如果该数组或集合是无序的那前提要排序sort，该查找方式是每次查找先将搜索范围缩小一半
- .copy(list  , list2  ) 
- .fill(list,  " 123  ")替换填充每个元素
- .max   返回集合最大值
- .replaceAll(list , " aa ",  " bb ")  返回同时将指定元素替换
- .reverse( list )   反转集合元素
- .shuffle  打乱元素

## Arrays
- 提供数据操作的工具类
	- 排序（sorting）  Arrays.sort(arrs);
	- 搜索（searching）
	- 比较（comparison）
	- 填充（filling）
	- 复制（copying）
	- 转换为列表（converting to List）
	- 输出为字符串（output to String）
	- 哈希码（hashing）
